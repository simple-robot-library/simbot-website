# 版本语义

simbot的 [核心库](https://github.com/simple-robot/simpler-robot)
和由我们维护的组件库的版本均具有语义。

我们参照并基本遵守 [**《语义化版本 2.0.0》**](https://semver.org/lang/zh-CN/spec/v2.0.0.html) 。
引用文档内的规则说明：

<note>
版本格式：主版本号.次版本号.修订号，版本号递增规则如下：

1. 主版本号：当你做了不兼容的 API 修改，
2. 次版本号：当你做了向下兼容的功能性新增，
3. 修订号：当你做了向下兼容的问题修正。

先行版本号及版本编译信息可以加到“主版本号.次版本号.修订号”的后面，作为延伸。
</note>

自 `5.0` 起，主仓库内的标准库、核心库、公共库、扩展库，以及 QQ、KOOK、OneBot 组件统一版本发布。
第三方组件仍由各自的维护者管理版本。

`5.0` 之前，核心库与官方组件库的版本独立维护。
例如核心库的 `4.3.0` 和 QQ 机器人组件的 `4.0.0-beta1` 之间没有强关联。

当前 `5.x` 仍处于 alpha 阶段，手册将 `5.0` 的 preview、alpha 等预发布更新统一标记为 `5.0`。
具体变更与迁移说明见 [](migration-5.0.md)。
