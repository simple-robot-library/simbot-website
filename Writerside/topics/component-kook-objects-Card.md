# Card

> 官方文档: [卡片消息](https://developer.kookapp.cn/doc/cardmessage)

API 模块的 `CardMessage` 表示卡片消息，`Card` 表示其中的一张卡片。
组件模块提供 `KookCardMessage` 消息元素。发送消息时可参考
[](component-kook-message-element.md) 和 [](component-kook-message-send.md)。
